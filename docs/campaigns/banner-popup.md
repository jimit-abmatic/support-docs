# Banner & Popup Campaigns

:::info This page has moved
**Banner & Popup** campaigns are now called **Widget** campaigns. The content has moved to **[Widget Campaigns](/campaigns/widget)**.

The new URL slug is `/campaigns/widget/...`. Old `/campaigns/banner_popup/...` links still resolve, so existing bookmarks keep working.
:::

Widget campaigns let you layer on-page widgets — **banner**, **popup**, **exit-intent modal**, the new **sidebar widget**, and **agentic chat** — on top of your existing pages without changing your website code. Popup and exit-intent widgets also include a **HubSpot form picker**.

See **[Widget Campaigns](/campaigns/widget)** for the full guide.
